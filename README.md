# Hands-On Data Lab Implementation
## Sales Data Analysis

This project demonstrates practical data analysis using Python, Pandas, NumPy, Matplotlib and Jupyter.

### Exercises
- Data loading and inspection
- Data types and missing-value checking
- Data cleaning
- Descriptive statistics
- Grouping and aggregation
- Correlation analysis
- Data visualization

### Run
`pip install -r requirements.txt`
`python analysis.py`

The dataset is synthetic and intended for educational use.
